# Movie Rating Prediction with Python

This project predicts movie ratings using machine learning regression techniques.

## Project Objective
To analyze historical movie data and predict movie ratings based on:
- Genre
- Director
- Actor
- Release Year

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## How to Run the Project
1. Install required libraries:
   pip install -r requirements.txt

2. Run the program:
   python movie_rating_prediction.py

## Output
- Model evaluation metrics (MAE, RMSE, R2 Score)
- Predicted rating for a sample movie

## Use Cases
- Movie recommendation systems
- Streaming platforms
- Film industry analysis
