# 📈 Sales Prediction Using Python

This project predicts product sales based on advertising expenditure using machine learning regression techniques.

---

## 📌 Project Objective
To forecast future sales by analyzing advertising budgets across multiple platforms such as TV, Radio, and Newspaper. The project helps businesses optimize advertising strategies and maximize sales potential.

---

## 📊 Dataset Description
The dataset contains:
- TV advertising budget
- Radio advertising budget
- Newspaper advertising budget
- Sales (target variable)

Sales prediction is a **regression problem**.

---

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

---

## 🧠 Machine Learning Approach
- Supervised Learning
- Linear Regression Model
- Train-test split (80% training, 20% testing)

---

## 📈 Model Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
